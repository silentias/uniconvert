# Измерения производительности UniConvert

Дата: 19 октября 2026 года. Измерена готовая release-сборка CLI для Windows; desktop-интерфейс в измерения не входит.

Компьютер: AMD Ryzen 7 5700X, 8 ядер / 16 потоков, 17 102 315 520 байт физической памяти (15,93 ГиБ), Windows 11 Pro, версия 10.0.26300.

## Методика

Входные файлы синтетические, создаются локально через FFmpeg. Генерация файлов не входит во время конвертации. Для аудио и видео выполнены один прогревочный и три измеряемых запуска; приведена медиана полного времени выполнения процесса. При сравнении используется один и тот же FFmpeg, одинаковые кодеки и параметры. UniConvert дополнительно выполняет анализ через FFprobe. Измерения последовательные, на работающей пользовательской системе, без изоляции фоновой нагрузки.

Память: максимальная наблюдаемая сумма Working Set новых процессов uniconvert, ffmpeg и ffprobe, с опросом примерно каждые 20 мс. Это оценка пика резидентной памяти, а не гарантированный абсолютный максимум; время аудио/видео включает накладные расходы мониторинга и ожидания завершения. Для короткого анализа Gerber выполнены отдельные 30 запусков без мониторинга памяти, с измерением времени через Node.js performance.now. Для десяти изображений выполнены три серии после прогрева. В каждой серии одно тестовое изображение конвертируется десять раз последовательными вызовами CLI; это не встроенный пакетный режим и не выборка из десяти разных фотографий.

## Результаты

| Задача | UniConvert CLI | Прямой FFmpeg |
| --- | ---: | ---: |
| Видео 60 с, 1280×720, 30 кадров/с, MP4 → AVI, H.264 CRF 23 + AAC 192 кбит/с | 4,653 с | 4,534 с |
| Аудио 60 с, WAV 48 кГц, стерео → MP3 192 кбит/с | 0,630 с | 0,493 с |
| 10 последовательных PNG → JPEG, 1920×1080, качество 80 | 0,617 с | не измерялось |
| Чтение и анализ Gerber с 1000 линиями | 0,0219 с | неприменимо |

Максимальная наблюдаемая память видео: UniConvert с дочерними процессами — 466,6 МиБ, прямой FFmpeg — 462,3 МиБ. Аудио: 20,8 и 15,9 МиБ соответственно. Размер uniconvert.exe — 4 747 776 байт (4,75 МБ / 4,53 МиБ). Использованные FFmpeg и FFprobe занимают ещё 82 797 568 и 63 059 968 байт; суммарно три файла — 150,61 МБ. Это не размер установщика desktop-приложения.

Все измеряемые команды завершились успешно. Содержимое Gerber-ответа проверено: 1000 линий и отсутствие структурных ошибок. Выходные аудио и видео дополнительно проверены FFprobe. Сравнение не является независимым сравнением кодировщиков: UniConvert использует FFmpeg. Онлайн-сервисы и DOC/DOCX/PDF не измерялись.

## Воспроизведение

Скрипты текущего рабочего окружения: `.verification/benchmark.ps1` и `.verification/benchmark-timing.mjs`. Сырые результаты: `.verification/benchmark/results.json`, `summary.json`, `timing.json`. Каталог `.verification` содержит локальные зависимости и может не входить в систему контроля версий.
