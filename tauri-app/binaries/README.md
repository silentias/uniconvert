# Sidecar binaries

Для конвертации, анализа и расчёта прогресса положите сюда `ffmpeg.exe` и `ffprobe.exe` на Windows или `ffmpeg` и `ffprobe` на Linux/macOS.

Во время разработки ядро ищет оба инструмента в следующем порядке:

1. Пути из переменных `UNICONVERT_FFMPEG_PATH` и `UNICONVERT_FFPROBE_PATH`.
2. Этот каталог `tauri-app/binaries`.
3. Рядом с исполняемым файлом приложения.
4. Системный `PATH`.

Перед распространением приложения бинарник нужно добавить в bundle с учётом его лицензии и целевой платформы.
