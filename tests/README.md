# Тестовые Gerber-файлы

Синтетические примеры, использованные для ручной проверки release-CLI и измерений производительности. Они не экспортированы из CAD и не предназначены для изготовления платы. Значение KiCad в метаданных задано вручную для проверки чтения атрибутов.

| Файл | Назначение и ожидаемый результат |
| --- | --- |
| `gerber-1000-lines.gbr` | Файл из замеров: 1000 последовательных линейных операций, одна круглая апертура D10, единицы мм, формат координат X/Y 4.6. Текущий анализатор не сообщает структурных проблем и замечаний по D-кодам. |
| `gerber-metadata-and-d-codes.gtl` | CAD: KiCad · Pcbnew · 9.0; дата: 2026-10-14T10:15:00+03:00; слой Copper, сторона top; мм, X/Y 4.6. Статистика: 2 линии, 1 дуга, 1 вспышка, 1 область. Намеренные проблемы D-кодов: D11 без определения, D12 не используется, D10 определён повторно. Структурный отчёт текущего анализатора пуст; это не означает полной корректности геометрии. |
| `gerber-invalid-structure.gbr` | Повреждённый файл с UTF-8 BOM. Ожидаются 5 ошибок: нет MO, повреждён ADD, рисование без выбранной апертуры, незакрытая область G36, нет M02. Два предупреждения: неизвестная G99 и устаревшая G74. |

Открытие в приложении: раздел «Извлечь Meta», затем выбор файла.

Проверка из корня проекта:

```powershell
.\release\win\uniconvert-cli.exe gerber-meta ".\tests\gerber-1000-lines.gbr" --json
.\release\win\uniconvert-cli.exe gerber-meta ".\tests\gerber-metadata-and-d-codes.gtl" --json
.\release\win\uniconvert-cli.exe gerber-meta ".\tests\gerber-invalid-structure.gbr" --json
```

Все три файла повторно проверены через release-CLI 19 октября 2026 года. Они дополняют автоматические тесты парсера в `tauri-app/core/src/analysis/gerber/mod.rs` и интеграционный тест CLI в `tauri-app/cli/tests/media.rs`. Полная совместимость со стандартом и геометрическая корректность этими проверками не подтверждаются.
